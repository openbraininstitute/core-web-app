## 🏠 LEAVE-AS-FEATURE (21)

Domain-aware, has data fetching, or is app-shell infrastructure. These don't
belong in the design system; they should stay in `src/components/` (or move to
`src/features/` / `src/providers/` later).

### App infrastructure (providers / wrappers)

- `ThemeProvider` — jotai theme atoms. → `src/providers/theme` eventually.
- `SessionStateProvider` — session hook wrapper. → `src/providers/session`.
- `Matomo` — analytics. → `src/lib/analytics`.
- `DefaultLoadingSuspense` — Suspense boundary with AntD spin. → `src/ui/providers`.

### Domain features

- `ai-assistant` — full AI chat UI.
- `neuron-viewer`, `MorphoViewer` — domain visualization.
- `user-menu`, `HelpMenu`, `main` — app navigation.
- `Link` — Next.js link wrapper with search-param preservation.
- `Search` — AntD select-based domain search.
- `FilterControls` — generic-ish but tightly coupled to data-grid usage.
- `github-flavor-markdown` — markdown renderer with math + GFM.
- `documentation`, `explore-section`, `experiment-interactive`,
  `tutorials-carrousel`, `simulate`, `viewers`, `connectome-definition` —
  feature-specific pages or widgets.
- `message-banners` (`ErrorData`) — error UI banner; could promote later.

### Special: `icons`

15 consumers. Mixes custom SVG (Brain, Chevron, Settings) with AntD icons. This
contradicts the design-system rule "Remix only". Two options:

1. **Replace AntD bits with Remix**, keep custom SVG (brand-specific glyphs).
2. **Move custom SVG to `src/ui/assets/icons`** and let app code import from
   `@remixicon/react` for everything else.

Recommend option 2 — it draws a cleaner line.
