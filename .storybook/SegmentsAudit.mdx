# `src/ui/segments/*` — Composition Audit

24 segments audited for how cleanly they sit on top of the design-system molecules.
A healthy composition only consumes molecules + raw HTML; an unhealthy one reaches
around them to import `antd` visual primitives or hardcodes hex colors.

---

## Summary

| Verdict | Count |
| --- | --- |
| ✅ HEALTHY | 12 |
| ⚠️ REFACTOR-LATER | 9 |
| 🔧 NEEDS-WORK | 3 |

**50% of segments have zero significant design-system debt.** The debt is
concentrated in form-heavy areas (workflows, contribute) and in the data-grid
machinery (data-table, explore/circuit).

---

## 🔧 NEEDS-WORK (3) — refactor first

### `workflows`

Heavy AntD form usage (27 imports) + 32 hex color literals. Builds neural
simulation forms directly with `antd` `Form`/`InputNumber`/`Select`/`Switch`/etc.
This is where most of the design-system debt lives.

- Replace AntD form primitives with the corresponding molecule (or add the missing
  ones — there's no `InputNumber` or `DatePicker` molecule yet).
- Centralize plot color tokens.

### `contribute`

30 AntD imports for multi-step contribution forms. Same shape as `workflows` —
form complexity drives the AntD direct usage.

- Build a `form-builder` molecule (or move to `react-hook-form` + molecule
  controls).

### `explore/circuit`

10 AntD imports + 13 hex literals. Circuit table styled with inline AntD theme,
not tokens.

- Wrap `Button` from molecules everywhere.
- Move table styling tokens to `globals.css`.

---

## Observations

- **Form-heavy areas are where the design system breaks down.** Either build
  molecule-wrapped form controls (`<FormInput>`, `<FormSelect>`, `<FormNumber>`)
  or adopt a form library (react-hook-form, formik) with molecule controls.
- **Color literals cluster in three places**: plot/visualization configs (Plotly),
  shadow definitions, and inline AntD theme overrides. Each can be tokenized.
- **Strong molecule adoption** in healthy segments (workflows uses 70 molecule
  imports despite its smells) → the molecules ARE discoverable and useful, the
  AntD usage is gap-driven, not preference-driven.

---

## Recommended order

1. **`workflows`** — highest impact. Build the missing form-control molecules
   first, then migrate. Big PR, but pays off everywhere.
2. **`contribute`** — apply the form-builder pattern from step 1.
3. **`explore/circuit`** — tokenize the table styles.
4. Sweep the 9 REFACTOR-LATER segments in a single PR per segment (each is small).
