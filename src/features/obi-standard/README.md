# obi-standard (feature)

Renders **the OBI Standard** — the entitycore/entitysdk entity types, their properties and
accepted files. Here it is the Learn page's Standard section (`features/learn/ui/standard.tsx`):
the entity types listed by category on the left, the chosen one's `<StandardEntityDetail/>` on the
right. Taken from the `obi_standard` branch, where it sat inside the Data browser instead.

## Data

`data/standard-data.json` is a **pre-resolved snapshot** (~130 KB): each entity already carries its
resolved properties (types, enums, references), its common envelope fields, its accepted-file
rules, and its ready-to-copy **entitysdk** snippets (fetch / query / register / upload). No OpenAPI
resolver or snippet builder runs in this app.

It is generated by the sibling `obi-standard` project, which reads the entitycore OpenAPI schema
(live or its bundled snapshot) plus the asset-label rules in `entitycore/app/db/types.py`.

### Refreshing the snapshot

`scripts/patch_from_entitycore.py` rebuilds every entry from entitycore's live OpenAPI schema, its
pydantic Read classes (which parent class each field comes from) and its asset-label rules, adds
the task entries (TaskConfig, TaskActivity, one per TaskResultType) and obi-one's endpoints for a
validated registration. Run it with entitycore's Python, an up-to-date checkout on the path:

```bash
PYTHONPATH=../entitycore ../entitycore/.venv/bin/python \
  src/features/obi-standard/scripts/patch_from_entitycore.py
```

The entries' titles and descriptions are kept; to add or re-describe entities, edit the snapshot
(or the generator in the sibling `obi-standard` project, then re-run this script).
